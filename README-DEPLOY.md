# Οδηγίες ανάρτησης — Naxos Balcony Apartments

## 0. Το πακέτο ανεβάσματος

```bash
python3 tools/gen/package.py     # φτιάχνει το naxos-deploy.zip
```

Βγάζει **311 αρχεία, ~20,7 MB**, έτοιμα για εξαγωγή μέσα στο `public_html`.
Δουλεύει με **λίστα επιτρεπομένων**: μπαίνει μόνο ό,τι είναι ρητά μέσα στο
`tools/gen/package.py`, και στο τέλος ελέγχει το τελικό zip — αν βρει αρχείο
δεδομένων, κωδικό ή δοκιμή, σταματά με σφάλμα.

**Τι ΔΕΝ μπαίνει ποτέ:** `credentials.php`, `*-data.php`, `.login-attempts*`,
`staff.json`, τα `welcome/<όνομα>-<κωδικός>.php` (προσωπικά λινκ πελατών), τα
`*.md`, τα `tests/`, τα `tools/` και το `preview/`.

> **⚠️ Γιατί τα `*.md` και τα `tests/` μένουν έξω:** περιέχουν τους
> δοκιμαστικούς κωδικούς (`demo1234`, `acc1234`, `cln1234`). Ο server είναι
> **nginx**, που **δεν** διαβάζει το `.htaccess` — αν ανέβαιναν, θα ήταν
> **δημόσια** σε όποιον μάντευε το όνομα.

> **Για το ανέβασμα βήμα-βήμα, δες το `DEPLOY-CPANEL.md`.** Αυτό το αρχείο
> κρατά τις τεχνικές λεπτομέρειες και το ιστορικό.

## 2. Ανέβασμα στον server

Ανέβασε **τα περιεχόμενα** του `naxos-deploy.zip` (ή του repo, που έχει το site
στη ρίζα) μέσα στο `public_html`:

```
index.html  gallery.html  amenities.html  weather.html  contact.html
forecast-pro.html  privacy.html  cookies.html  404.html
en/  images/gallery/  admin/  welcome/  fonts/
styles.css  fonts.css  fonts/  site.js  consent.js  lang-nav.js  pro.js  lang-system.js
gallery-data.js  gallery-tiles.json
robots.txt  sitemap.xml  site.webmanifest  .htaccess  welcome/
favicon.ico  favicon-32.png  favicon-192.png  favicon-512.png  apple-touch-icon.png
og-image.jpg  naxos-balcony-apartments-glinado-view-*.jpg
```

### ⚠️ ΜΗΝ σβήσεις αυτά που υπάρχουν ήδη στον server

- `api/` — τα `weather-*.php` που τραβάει ο μετεωρολογικός σταθμός
- `naxos-balcony-apartments-glinado-view.jpg` (το μεγάλο, 3600px — το χρησιμοποιεί
  το Open Graph για Facebook/Instagram)
- `logo-naxos-balcony.png`, `favicon-naxos-balcony.png`

### Ο φάκελος admin

1. Ανέβασε το `admin/index.php`.
2. Άνοιξε `https://www.naxosbalcony.gr/admin/` — θα σου ζητήσει κωδικό.
3. **Βάλε δικό σου κωδικό** (τουλάχιστον 8 χαρακτήρες).
4. Ο κωδικός αποθηκεύεται κρυπτογραφημένος στο `admin/credentials.php`, που
   **δεν ανεβαίνει ποτέ στο GitHub** (είναι στο `.gitignore`).

Αν χάσεις τον κωδικό: σβήσε το `admin/credentials.php` και ξαναάνοιξε τη σελίδα.

Μετά από 5 αποτυχημένες προσπάθειες σύνδεσης ο λογαριασμός κλειδώνει για
15 λεπτά. Η κατάσταση κρατείται στο `admin/.login-attempts.json` (δεν
ανεβαίνει στο GitHub). Αν κλειδωθείς, περίμενε ή σβήσε αυτό το αρχείο.

### Ο προεπιλεγμένος κωδικός WiFi

Ο κωδικός του ρούτερ **δεν είναι γραμμένος στον κώδικα**. Τον αλλάζεις από τη
σελίδα **«Links επισκεπτών»** (`admin/guests.php`), στην κάρτα **«Προεπιλεγμένος
κωδικός WiFi»**. Μία αλλαγή και ισχύει για όλες τις κρατήσεις που δεν έχουν δικό
τους κωδικό. Άφησε το πεδίο κενό για να επιστρέψει στο `NAXOS2027`.

Όταν αλλάξεις τον προεπιλεγμένο, **οι παλιές κρατήσεις ενημερώνονται αυτόματα**:
όσες είχαν ακριβώς τον παλιό κωδικό αδειάζουν και ακολουθούν τον νέο· όποια είχε
**δικό της** κωδικό τον κρατά.

Πού φυλάσσεται: με τον ίδιο ασφαλή τρόπο με τα δεδομένα επισκεπτών. Αν υπάρχει
εγγράψιμος φάκελος έξω από το `public_html` (ο `naxos-data/`), το αρχείο πάει
εκεί — αλλιώς μένει στο `admin/settings-data.php`, που **δεν τυπώνει τίποτα** αν
το ζητήσει κάποιος από τον browser. Και στις δύο περιπτώσεις δεν ανεβαίνει ποτέ
στο GitHub (είναι στο `.gitignore`).

### Οι γραμματοσειρές

Το `fonts.css` και ο φάκελος `fonts/` (4 αρχεία `.woff2`, ~160 KB) πρέπει να
ανέβουν μαζί με τα υπόλοιπα. Η Inter φιλοξενείται τοπικά αντί για το
`fonts.googleapis.com`: έτσι δεν μπλοκάρει το πρώτο ζωγραφίσμα της σελίδας και
δεν στέλνεται η IP του επισκέπτη στη Google. Για να τα ξαναφτιάξεις:

```bash
python3 tools/gen/fonts.py     # κατεβάζει τα woff2 + γράφει το fonts.css
python3 tools/gen/thumbs.py    # φτιάχνει τα 700px thumbnails της συλλογής
python3 tools/gen/build.py     # ξαναχτίζει τις σελίδες
```

Τα thumbnails (`*-thumb.webp` / `*-thumb.jpg` δίπλα σε κάθε φωτογραφία) είναι
απαραίτητα: χωρίς αυτά το πλέγμα της συλλογής θα φόρτωνε ξανά ~15 MB.

Χρήση: διάλεξε δωμάτιο → διάλεξε πολλές φωτογραφίες μαζί → Ανέβασμα.
Οι φωτογραφίες μικραίνουν αυτόματα, καθαρίζονται από GPS/EXIF και
μπαίνουν στη σελίδα αμέσως, και στα ελληνικά και στα αγγλικά.

## 3. Σημαντικό: ο server είναι nginx

Το επιβεβαίωσα στις 23/10/2026: το site σερβίρεται από **nginx**, που **αγνοεί
το `.htaccess`**. Δεν ισχύει σήμερα:

- redirect http → https
- redirect χωρίς-www → www
- δική μας σελίδα 404
- headers ασφαλείας
- caching

Δεν είναι κάτι που έσπασε τώρα — έτσι ήταν ήδη. Το `.htaccess` που ανεβαίνει
είναι για την περίπτωση που μεταφερθείς σε Apache, και στο τέλος του έχει έτοιμο
το αντίστοιχο nginx αρχείο. Αν θέλεις να ισχύσουν τώρα, στείλε το nginx κομμάτι
στην υποστήριξη του hosting.

**Δεν άλλαξα τα URLs** γι' αυτόν τον λόγο. Όλοι οι σύνδεσμοι γράφουν
`index.html` ολόκληρο, οπότε δουλεύουν και χωρίς `DirectoryIndex`.

## 4. Έλεγχοι που πέρασα

- **Κείμενο**: λέξη-προς-λέξη σύγκριση με το ζωντανό site. Δεν άλλαξε τίποτα.
  Οι μόνες διαφορές είναι προσθήκες (cookie banner, σύνδεσμοι Απόρρητο/Cookies,
  skip link).
- **Responsive**: 375 / 768 / 1280 px σε όλες τις 18 σελίδες — κανένα οριζόντιο
  σκρολάρισμα.
- **Σπασμένες εικόνες**: 0, σε όλες τις σελίδες και στις δύο γλώσσες.
- **Αγγλικά**: 0 ελληνικά κείμενα που ξέμειναν.
- **Αντίθεση**: το «ΚΑΛΕΣΤΕ ΜΑΣ» από 3.70:1 (αποτυχία) → 4.95:1 (περνά WCAG AA).
- **Ασφάλεια admin**: δοκίμασα upload/διαγραφή χωρίς σύνδεση, λάθος CSRF token,
  και path traversal (`../../`) — όλα απορρίπτονται.
- **Cookies**: το analytics ξεκινάει κλειστό και ανοίγει μόνο με «Αποδοχή».
  Δεν το προ-ενεργοποίησα: τα προ-τικαρισμένα cookies δεν είναι νόμιμη
  συγκατάθεση κατά τον GDPR.

## 5. Αν ξαναχρειαστεί να βγάλεις σελίδες

```bash
cd tools/gen
python3 build.py     # γράφει τις 18 σελίδες + sitemap.xml
```

Οι σελίδες **παράγονται** — μην τις πειράζεις με το χέρι, οι αλλαγές θα χαθούν.
Πείραξε τα `*_body.html` και τα `translations.json`.
